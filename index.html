러브 메모리

1인 개발 · 운영React / Next.js / Firebase
어떻게 만들었나요? ＋
문제

결과
기획·디자인·구현·테스트·배포를 직접 담당했습니다. 비공개 테스트 이후 정식 출시했고, 실사용자 피드백을 반영하며 운영 중입니다.

02 / TEAM · 2024.08—12

미마미

개발 후반, 팀의 완성을 맡다.

16인 팀의 보스전 중심 액션 게임. 프로그래머로 시작해 후반부 PD를 이어받고, 기능 범위와 작업 우선순위를 재정비했습니다.

PD · 프로그래머Unreal Engine 5.4
어떤 판단을 했나요? ＋
문제
중간 시연 이후 추가 콘텐츠와 조작감·충돌 버그 개선을 함께 처리해야 했습니다.
내 결정
회의 내용을 TODO로 정리하고 추가 기능과 품질 개선을 분리했습니다. 일부 공격 기믹을 보류하고, 튜토리얼은 기존 보스 리소스를 활용한 잡몹과 기존 맵 중심으로 범위를 잡았습니다.
결과
후반부 PD를 겸임하며 빌드를 완주했습니다. 프로젝트 결과는 교과목 A+이며, 종료 후 포스트모템으로 협업 과정을 돌아봤습니다.

직접 구현한 것

  • 액션 시스템 설계와 FSM 리팩터링
  • HitStop, Camera Shake 등 타격감 요소와 카툰 렌더링
  • 프로파일링 후 Planar Reflection 비용 조정
  • UPROPERTY 누락에 따른 UObject 참조·수명 관리 문제 수정

일정 양식은 팀 PM이 작성했습니다. 제 기여는 개발 업무 수행, 중간 시연 회의록 정리, 후반부 PD 인수와 우선순위 조정입니다.

03 / GAME JAM · 2024.07

빛을 향해서

기능을 줄이고, 재미를 다듬다.

3명이 5일간 만든 변신 퍼즐 게임. 핵심 플레이를 먼저 완성하고 연출을 다듬어 청강대 × 유니티 게임잼 우수상을 받았습니다.

PD · 프로그래머Unity / Live2D
무엇을 남기고 줄였나요? ＋
문제
개발 이틀째, 계획한 기능을 모두 구현하기에는 시간이 부족하다고 판단했습니다.
내 결정
변신 시스템과 기초 스테이지를 MVP로 정했습니다. 3일 내 핵심 구현을 끝내고 남은 2일은 카메라·이펙트·Live2D·사운드에 집중했습니다.
결과
5일 대면 개발을 마치고 12개 팀 중 우수상을 받았습니다. 시상일은 2024년 8월 7일입니다.

직접 구현한 것

  • 변신 시 스탯·스킬셋·애니메이터를 교체하는 구조
  • Live2D SDK 연동과 시선 추적
  • 시스템 / 스테이지·기믹 / 아트로 작업 범위 분리
DAY 1—3변신 + 기초 스테이지
DAY 4—5연출 + 폴리싱

01

먼저, 범위를 정합니다

남은 시간에 맞춰 핵심 플레이와 추가 기능을 나눕니다. 빛을 향해서에서는 MVP 이후 이틀을 폴리싱에 남겼습니다.

02

함께 만들 수 있게 합니다

UML, Git·Blueprint 가이드, 리소스 명명 규칙을 정리했습니다. 기획자가 직접 시스템을 조정할 수 있는 도구도 만들었습니다.

03

빌드로 확인합니다

주기적으로 빌드를 올려 직접 플레이하고 문제를 정리했습니다. 오류는 재현 조건을 좁히고, 성능은 프로파일링으로 원인을 확인했습니다.

원본의 발췌 요약입니다. 완료율이나 일정 단축 효과를 계산한 자료가 아니며, 팀의 일정 양식 작성과 제 업무 기여를 구분했습니다.

완주 이후 남은 과제

포스트모템에는 소통과 일정 운영의 아쉬움도 남았습니다. 변경 이유와 담당 범위, 진행 상황을 더 일찍 공유하는 것을 다음 협업의 개선 과제로 삼습니다.

중단한 프로젝트에서 배운 것 ＋

버니 프로젝트 · Unity / TD

20인 팀으로 진행한 3D 액션 프로젝트는 출품 전에 중단됐습니다. 리소스 재배치를 제안했지만, 실행 가능한 대안과 합의 기준을 충분히 준비하지 못했습니다.

리스크를 발견하는 것에서 끝내지 않고, 선택 가능한 대안과 각 대안의 일정 영향을 함께 제시해야 한다는 과제를 남겼습니다. 이후 빛을 향해서에서는 핵심 기능을 먼저 정하고 완주 가능한 범위로 개발했습니다.
