# 김도윤 · 개발 PM | 버그 콜렉터

밝은 배경과 큰 프로젝트 이미지 중심의 정적 채용 포트폴리오입니다. GitHub Pages에서 빌드 없이 제공합니다.

## 구성

- `index.html`: 미마미 → 버니 프로젝트 → 빛을 향해서 → 러브 메모리, 일하는 방식, 소개, 근무 가능 일정
- `case-pr-mimami.html`: 제작 범위 조율, 팀 운영, 중간·최종 시연, 작업 기록
- `case-pr-apocalypse.html`: 기획 질의서, 결정권·전달 절차, 범위 조정·알파 테스트, 중단 결과와 작업 기록
- `case-pr-jam.html`: 처음부터 계획한 3일 구현·2일 폴리싱과 수상
- `case-love-memory.html`: 제품 방향, 출시, 운영 중 알림 수신 문제 수정
- `archive.html`: 프로젝트 24개(C·C++ 수업 과제 6개는 카드 하나로 묶음)와 검색·분류 필터
- `document.html`: 기존 문서 링크를 메인으로 연결
- `assets/css/portfolio.css`: 공통·아카이브 스타일
- `assets/css/editorial.css`: 메인·대표 사례의 데스크톱·모바일·인쇄 스타일
- `assets/js/portfolio.js`: 영상 창, 썸네일 대체 처리, 검색, 인쇄

## 실행과 배포

`python -m http.server 8765`로 확인합니다. main 브랜치 루트가 GitHub Pages 게시 원본입니다.

미마미와 빛을 향해서에는 기존 게임 화면 이미지를 사용합니다. 러브 메모리와 중간 시연에는 YouTube 썸네일을 사용하며 낮은 해상도의 썸네일로 대체할 수 있습니다. 영상 창은 `youtube-nocookie.com`을 사용하고 Escape로 닫힙니다. JavaScript 없이도 외부 영상과 사례 링크에 접근할 수 있습니다. 최종 시연은 기존 영상의 329초 시작 위치를 유지합니다.
