# 김도윤 · 개발 PM | 버그 콜렉터

밝은 배경과 큰 프로젝트 이미지 중심의 정적 채용 포트폴리오입니다. GitHub Pages에서 빌드 없이 제공합니다.

## 구성

- `index.html`: 미마미 → 버니 프로젝트 → 빛을 향해서 → Dirty Guilty → 러브 메모리, 일하는 방식, 소개, 근무 가능 일정
- `case-pr-mimami.html`: 제작 범위 조율, 팀 운영, 중간·최종 시연, 작업 기록
- `case-pr-apocalypse.html`: 기획 질의서, 결정권·전달 절차, 범위 조정·알파 테스트, 중단 결과와 작업 기록
- `case-pr-dirty-guilty.html`: WBS 작업 분배, QA 시트 104건 추적, KOG 현업 피드백
- `case-pr-jam.html`: 처음부터 계획한 3일 구현·2일 폴리싱과 수상
- `case-love-memory.html`: 제품 방향, 출시, 운영 중 알림 수신 문제 수정
- `archive.html`: 프로젝트 24개(C·C++ 수업 과제 6개는 카드 하나로 묶음)와 검색·분류 필터
- `document.html`: 기존 문서 링크를 메인으로 연결
- `assets/css/portfolio.css`: 공통·아카이브 스타일
- `assets/css/editorial.css`: 메인·대표 사례의 데스크톱·모바일·인쇄 스타일
- `assets/js/portfolio.js`: 영상 창, 썸네일 대체 처리, 검색, 인쇄

## 실행과 배포

`python -m http.server 8765`로 확인합니다. main 브랜치 루트가 GitHub Pages 게시 원본입니다.

미마미와 빛을 향해서에는 기존 게임 화면 이미지를 사용합니다. 러브 메모리와 중간 시연에는 YouTube 썸네일을 사용하며 낮은 해상도의 썸네일로 대체할 수 있습니다. 영상 창은 `youtube-nocookie.com`을 사용하고 Escape로 닫힙니다. JavaScript 없이도 외부 영상과 사례 링크에 접근할 수 있습니다. 최종 시연은 기존 영상의 329초 시작 위치를 유지합니다.

## 문장 직접 편집 · 비밀번호 로그인

화면 오른쪽 아래 **문장 수정** → 비밀번호 입력 → 문장 클릭 → **저장**.
메인, 아카이브, 상세 사례 5개 페이지에서 제목·본문·목록·표·링크의 표시 문구를 수정합니다. 이미지, 링크 주소, 레이아웃은 유지합니다. 각 페이지에서 따로 저장하며 Ctrl/Cmd+S도 지원합니다. Shift+Enter로 줄바꿈합니다.

수정 문장은 별도 저장 서버에 보관되어 다른 기기와 공개 방문자에게도 적용됩니다. 편집 취소, 로그아웃, 저장 전 이동 경고, 다른 창의 수정 충돌 방지를 지원합니다. 원본 HTML은 초기 문장으로 유지되며 검색엔진/소셜 미리보기의 메타데이터는 별도로 수정해야 합니다.

- 서버: `https://portfolio-editor-api.kdystudy0426.chatgpt.site`
- 데이터: D1, 페이지별 문장 및 버전 저장
- 인증: 서버 비밀 설정 `EDITOR_PASSWORD`로 확인, 1시간 유효 세션, IP별 로그인 시도 제한
- 비밀번호와 세션 원문은 GitHub나 브라우저 저장소에 보관하지 않습니다.
- 비밀번호 변경은 저장 서버의 비밀 설정을 변경한 뒤 재배포합니다.
- `data-edit-id`는 저장된 문장 식별자이므로 기존 ID를 유지합니다. 새 문장을 추가하면 서버의 허용 필드 목록도 함께 갱신합니다.
- Firebase 설정은 필요하지 않습니다.
