유튜브 썸네일을 누르면 실제 영상을 볼 수 있습니다.

01 / PRODUCT DECISION

일정 공유를 넘어, 함께한 하루를 남기기

일정만 공유하는 앱은 이미 많았습니다. 저는 지난 날짜를 눌렀을 때 그날의 사진과 주고받은 이야기가 함께 보이는 경험에 집중했습니다. 슬로건은 ‘평소엔 조용하고, 돌아볼 때 좋은 앱’입니다.

하루를 한 화면으로

사진·기념일·일정·할 일·이야기를 날짜 하나의 시트에 모았습니다. 사용자가 그날의 기록을 확인하기 위해 탭 사이를 오가지 않게 했습니다.

사진을 날짜의 표지로

날짜 칸 배경에 그날의 사진을 배치했습니다. 달력을 넘기며 지난 몇 달을 사진으로 훑고, 위치를 붙인 기록은 지도에서 다시 볼 수 있게 했습니다.

02 / IMPLEMENTATION

작아 보이지만, 직접 풀어야 했던 문제

구현 요구와 선택한 구조
요구구현에서 다룬 문제적용한 방식
여러 날에 걸친 일정주 경계를 넘는 일정과 겹치는 일정의 가독성일정 띠를 주 단위로 나누고, 겹치는 일정은 줄을 나눠 배치
두 사람의 기록누가 등록했는지, 누구의 할 일인지 구분사진·일정에 작성 주체를 표시하고 할 일을 내 것과 파트너 것으로 분리
개인화테마를 바꿔도 화면 전체의 색상 일관성 유지색상을 변수로 통일하고 프리셋 8종과 5색 사용자 팔레트 지원
글씨 크기글자만 커져 주변 UI와 어긋나는 문제 고려기준 단위로 화면 크기를 조정하는 4단계 글씨 크기 지원

‘파트너가 올림’ 등의 표시는 화면 설계에 대한 설명입니다. 보안 규칙이나 접근 권한 검증의 증거로 제시하는 항목은 아닙니다.

03 / RELEASE & OWNERSHIP

구현에서 끝내지 않고, 출시와 운영까지

  1. 기획·디자인

    하루의 기록을 한곳에서 확인하는 흐름과 둘만의 공유 화면을 설계했습니다.

  2. 개발·비공개 테스트

    직접 기능을 구현하고 비공개 테스트 피드백을 반영했습니다.

  3. 정식 출시·운영

    Google Play에 출시한 뒤 실사용자를 받으며 운영하고 있습니다. 출시까지의 일정도 앱의 달력으로 관리했습니다.

이 프로젝트에서 보여주고 싶은 역량은 제품의 사용 흐름을 정의하고, 구현과 테스트를 거쳐 실제 배포까지 책임진 경험입니다.

출시·운영은 기존 포트폴리오의 본인 기록을 기준으로 정리했습니다. 개별 피드백 원문과 수정 전후 기록, 이용자·유지율 수치가 확인되지 않아 특정 개선 효과는 제시하지 않았습니다.
