# 러브 메모리 스크린샷

`assets/js/data/pages.js` 의 `love-memory` 쪽이 이 폴더의 파일을 이 이름 그대로 찾습니다.
파일을 넣으면 화면에 나타나고, **없으면 그 자리는 조용히 비워집니다** (깨진 이미지가 나오지 않습니다).

| 파일명 | 화면 |
| --- | --- |
| `calendar-month.jpg` | 월 달력 — 사진이 깔린 날짜, 여러 날 일정 띠 |
| `day-sheet.jpg` | 날짜 시트 — 사진 · 기념일 · 시간별 일정 · 할 일 |
| `day-story.jpg` | 이날의 이야기 — 남긴 말과 이모지 반응 |
| `photo-detail.jpg` | 사진 상세 — 대표 지정, 반응, 댓글, 위치 추가 |
| `settings-theme.jpg` | 테마 — 프리셋 8종, 색 직접 지정, 글씨 크기 |

캡션을 바꾸거나 사진을 더/덜 넣으려면 `pages.js` 의 `"t": "shots"` 블록만 고치면 됩니다.

가로 900px 안팎이면 충분합니다. 개인 정보(사진 속 얼굴, 실명 등)가 담기지 않았는지
올리기 전에 한 번 확인해 주세요 — 이 저장소는 공개되어 있습니다.
